First public version.

- Start empty, create your own sections (Economy, Sports, anything).
- Add news sites (any site with RSS, found automatically; Google News as a fallback) and YouTube channels.
- Optional daily check time per source.
- Optional AI filtering with a model you run yourself (Ollama or any OpenAI-compatible server).
- English and Turkish.

Downloads: `-android.apk` (Android 8+), `-macos.dmg` (macOS, Apple silicon), `-windows.msi` (Windows 10/11), `-linux.deb`.
The desktop builds are not code-signed yet; see the README for the one-time "open anyway" step.
